Okay, I opened this question out of curiosity because I was interested in seeing how hard a 4-star problem would be, but I don't actually think this one is that hard?
Famous last words. My plan is this: convert the given data into a vector of ints. Then, I will find the average of all the values in the vector. I will round this

After speaking to the tutor he suggested not doing this route. He implied something about how there are only 10 digits, and so there may be some we don't want to

do still need to think about cases where multiple values appear the same number of times. I think I'm just going to loop through and check all of them, that feels

Okay turns out I didn't totally understand what the tutor said. Turns out, I was going about it in a bad way (who would have thought!). The key thing I didn't

the array of integers again. I was really hesitant to do an entire brute force thing because of the way I wanted to do it, so I was trying to figure out a pattern
around which set of (i,i+1) would make it level with minimum effort, instead of finding a pretty good way to brute force it. Perhaps my nervousness around the 
average thing should have been a clue I was going on the wrong path. I'm also not super happy with how long that took me (1.5 hours), but it was a 4-star problem
so I'm going to cut myself a little bit of slack.
